# CLAUDE.md — Личный сайт Никиты Смирнова

## Что это
Мультистраничный сайт-портфолио на **Astro**. Витрина еженедельных деплоев +
личный бренд (история, философия, медиа). Язык — русский. Деплой — Netlify.
Эстетика: тёмный + премиальный фиолет, техно-самурай, японский минимализм.

## Команды
- `npm run dev` — локальный сервер (http://localhost:4321)
- `npm run build` — сборка в `dist/`
- `npm run preview` — предпросмотр собранного

## Архитектура
- `src/pages/` — страницы (Астро-роутинг по файлам):
  - `index.astro` — Главная (hero + последние проекты + входы)
  - `projects/index.astro` — сетка проектов + фильтры по тегам (клиентский JS)
  - `projects/[slug].astro` — страница проекта из markdown
  - `about.astro` · `media.astro` · `contact.astro`
- `src/content/projects/*.md` — **контент проектов**. Один файл = один проект.
- `src/content.config.ts` — схема карточки проекта (frontmatter).
- `src/layouts/Base.astro` — общий каркас: шрифты, nav, footer, reveal-анимация.
- `src/components/` — Nav, Footer, ProjectCard.
- `src/styles/global.css` — вся дизайн-система (переменные, компоненты).
- `public/` — статика (favicon).

## Как добавить новый проект (главный сценарий)
Создать файл `src/content/projects/имя.md` с frontmatter:
```yaml
---
title: Название
description: 1–2 строки для карточки
date: 2026-08-01
week: 3
tags: [бот, автоматизация, инструмент]
tryUrl: https://t.me/бот      # «Попробовать» (опционально)
githubUrl: https://github.com/...  # исходники (опционально)
# cover: ./обложка.png        # обложка (опционально; иначе кандзи-заглушка)
featured: true                # показывать среди последних
draft: false                  # true = скрыть
---
Тело в markdown: что делает, как пользоваться, стек.
```
HTML/код трогать не нужно — карточка и страница появятся сами.

## Заглушки под контент (заполнить)
- Фото: `about.astro` (.photo-slot) и обложки проектов.
- Тексты истории/философии в `about.astro` — черновик, уточнить из профиля/дневников.
- Ссылки «Попробовать» в проектах и ссылки в `media.astro`.

## Конвенции
- Кандзи-акценты — через класс `.jp` (шрифт Noto Sans JP).
- Дизайн только через переменные в `global.css`, инлайн-стили минимально.
- Ленивый минимализм (ponytail): без лишних зависимостей и фреймворков.
